# 🚀 Multi-Platform Course Extractor Bot

Ek advanced aur high-level Telegram bot jo India ke top education platforms se content (Videos/Notes) extract karne ke liye banaya gaya hai.

## ✨ Key Features
- **Multi-App Support:** PW, RWA, RG Vikramjeet, Careerwill, Utkarsh, Khan Global, aur Adda247.
- **Modular Architecture:** Har platform ke liye alag plugin file (e.g., `rg.py`, `rwa.py`).
- **Error-Free Code:** Pyrogram 2.0+ filters ke sath compatible (No `AttributeError: edited`).
- **Fast Processing:** Aiohttp aur Requests ka use karke fast API calls.
